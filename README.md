# Генератор рекламных описаний для заведений

Проект автоматически создает уникальные рекламные тексты для заведений на основе списка ссылок на их сайты с помощью GigaChat API.\
**Результат работы:** отдельные JSON-файлы, содержащие название страницы и сгенерированный рекламный текст.

## Требования:

- Python 3.9+
- **Зависимости.** Установите необходимые библиотеки:\
`pip install -r requirements.txt`
- **API-ключ.** Получите API-ключ в [GigaChat](https://developers.sber.ru/) и пропишите его в файле конфигурации `config/settings.yml`.
- **Входные данные.** Заполните файл `data/links.txt` ссылками на сайты заведений (по одной ссылке на строку).

## Запуск
Для выполнения скрипта перейдите в корневую директорию проекта и выполните команду: `python src/main.py`\
По завершении работы результаты (JSON-файлы) появятся в папке `output/`.

##  Структура проекта
Проект разделен на логические модули для удобства разработки и поддержки:
- requirements.txt — список зависимостей.
- config/settings.yml — конфигурация проекта (API-ключи, пути).
- data/links.txt — входные данные (ссылки).
- output/ — папка для выходных JSON-файлов. 
- src/ — исходный код приложения:
  + main.py — точка входа, запускает все этапы.
  + auth_token.py — получение токена доступа к API.
  + parser.py — получение заголовка страницы и генерация описания.
  + generator.py — асинхронное сохранение результатов.
  + utils.py — загрузка конфигурации из YAML.
  + logs/ — папка для хранения логов.
- README.md — инструкция по запуску и описание проекта.

## Пример использования

* Клонируем репозиторий:
```
git clone https://github.com/DaryaGovorkova/generator_ads.git
```
* Заполняем файл `data/links.txt`:
```
https://cafe1.ru 
https://bar2.ru
https://restoran3.ru
```

* Заполняем `config/settings.yml`:
```
api:
  api_key: "Authorization key"
  api_base: https://gigachat.devices.sberbank.ru/api/v1/chat/completions

paths:
  input_path: data/links.txt
  output_dir: data/output
```
* Запускаем скрипт:
```
python src/main.py
```
* Проверяем результат в папке `output/`. Вы увидите файлы вида cafe1.json, bar2.json. А в папке `logs` хранятся все логи к выполненным действиям.
